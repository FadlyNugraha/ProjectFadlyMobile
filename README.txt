# RuangKarya - proyek latihan Kotlin + XML

## Cara membuka
1. Ekstrak ZIP ini.
2. Android Studio: File > Open, pilih folder `RuangKarya_Latihan`.
3. Tunggu Gradle Sync selesai. Pastikan koneksi internet aktif agar dependensi dapat diunduh.
4. Jalankan pada emulator atau perangkat Android (minimum API 26).

## Konfigurasi
- Package: com.example.ruangkarya
- Kotlin + XML Views
- ViewBinding aktif
- minSdk 26, compileSdk 35
- Gradle Android Plugin 8.7.3, Kotlin 2.0.21
- JDK 17

## Isi aplikasi
- SplashScreen API
- BottomNavigationView dengan 3 Fragment
- ListView + BaseAdapter
- Toast saat item studio diklik
- Snackbar dengan aksi BATAL saat item ditekan lama
- Ringkasan tarif termurah dan termahal
- CardView dan Snackbar halaman informasi

Jika Android Studio meminta instalasi Android SDK 35 atau JDK 17, ikuti petunjuk instalasi dari Android Studio.
